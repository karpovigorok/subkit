# Security Policy

## Supported Versions

We take security bugs seriously. Currently, the following versions are being supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 2.x     | :white_check_mark: |

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

If you discover a security vulnerability within SubKit, please send an e-mail to Igor Karpov via [mail@noxls.net](mailto:mail@noxls.net).

All security vulnerabilities will be promptly addressed.
